# Transformer-based Energy Decay Curve Prediction
**ADSP – Topic 1–5: Generalized EDC Prediction from Room Geometry**

This repository contains a **Transformer-based deep learning model** for predicting
**Energy Decay Curves (EDCs)** from room geometry, material absorption, and
source/receiver positions.

The work extends the provided **LSTM baseline** by replacing it with a
Transformer encoder and evaluating performance using the same
EDC-based acoustic metrics.

---

## 📌 Project Scope
- Predict EDCs from room geometry and material properties
- Replace LSTM baseline with a Transformer architecture
- Evaluate using EDT, T20, and C50 (MAE, RMSE, R²)
- Ensure reproducibility via pretrained checkpoint and fixed evaluation script
